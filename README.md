# 💜 CollegeFest – Multiple College, One Platform

🎉 **CollegeFest** is a multi-college cultural event registration application designed to bring students from different colleges together on a single platform. It allows students to explore cultural events, view event details, register for competitions, make online payments, and manage their registrations easily.

The application provides a simple, attractive, and user-friendly interface with a beautiful purple and lavender colour theme.

⚙️ **Application Functionalities**
- Student login and registration.
- Multi-college event browsing.
- Event searching and category filtering.
- Event registration and participant details.

- Registration history and profile management.
- Notifications and settings.

## 🌟 Main Advantages

- Provides convenient online payment options.
- Helps students manage upcoming and past registrations.
- Offers a simple and attractive user experience.

## 💜 Conclusion

**CollegeFest is a student-friendly cultural event registration application that connects multiple colleges through one platform. It makes discovering events, registering for competitions, and managing payments easier. Its attractive purple and lavender theme, simple navigation, and useful features create an enjoyable experience for students.**
